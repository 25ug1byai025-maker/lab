Binomial Distribution

Models the number of successes in a fixed number of independent trials, each with the same success probability.

X ~ Binomial(n, p)

Poisson Distribution

Models the number of events occurring in a fixed interval when events happen at an average rate.

X ~ Poisson(λ)
